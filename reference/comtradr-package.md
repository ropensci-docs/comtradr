# comtradr: Interface with the United Nations Comtrade API

Interface with and extract data from the United Nations 'Comtrade' API
<https://comtradeplus.un.org/>. 'Comtrade' provides country level
shipping data for a variety of commodities, these functions allow for
easy API query and data returned as a tidy data frame.
